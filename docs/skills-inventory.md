## Recommended Learning Path

### Priority 1 (Start now — free or low cost)
- **Document everything** — before/during/after for every project
- **Google UX Design Certificate** (Coursera, ~$39/mo) — covers research, wireframing, prototyping, testing
- **Figma interactive prototyping** — YouTube tutorials + practice on a PM feature

### Priority 2 (Next 6 months)
- **Typography course** — Typewolf, Butterick's Practical Typography (free), or Skillshare
- **Color theory for digital** — check Interaction Design Foundation
- **Write 2-3 case studies** — FLD migration, one PM visualization, FlexFactory (if shareable)

### Priority 3 (Next year)
- **Motion design basics** — After Effects or Rive
- **Design systems deep dive** — Storybook, design tokens, component documentation
- **Informal user testing** — test PM visualizations with real users, document findings
